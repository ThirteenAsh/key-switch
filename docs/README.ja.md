## プロジェクト概要

*API Key が発行時にしか表示されず、あとから確認できなくて困ったことはありませんか？複数のプロバイダーに Key が分散し、必要なものを見つけにくいと感じていませんか？*

Key Switch は、さまざまなプロバイダーの API Key を一元管理するローカルデスクトップアプリです。用途メモの記録、利用可否の確認、必要なときの安全なコピーに対応します。

> Tauri 2、Vue 3、Rust、Vite を使用し、軽量・高速・安全なクロスプラットフォームのデスクトップ体験を目指しています。
